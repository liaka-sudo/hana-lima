# HANA LIMA — אפליקציית ניהול הכנסות והוצאות 💛

אפליקציית ווב פשוטה לניהול הכנסות והוצאות לעסק תכשיטים בעבודת יד.
בנויה ב-HTML/CSS/JavaScript רגיל + Firebase, עובדת מהטלפון, מסתנכרנת בזמן אמת בין כל המכשירים, והכול בעברית.

---

## מה יש באפליקציה

- **בית** — רווח/הפסד של החודש הנוכחי, רווח מצטבר מההתחלה, "כסף בדרך" (הזמנות שטרם שולמו), וגרף מגמה חודשית.
- **הוספת רישום** — טופס מהיר להכנסה או הוצאה (סכום, קטגוריה, סוג פריט כולל זהב/כסף, כמות, תאריך, אמצעי תשלום, צילום קבלה, הערות).
- **תנועות** — רשימה עם סינון לפי חודש, חיפוש, עריכה, מחיקה וצפייה בקבלה.
- **הזמנות** — הזמנות שממתינות לתשלום (שם לקוח/ה, פריט, סכום, סטטוס: חדשה/בהכנה/מוכנה/נמסרה). כפתור "שולם ✓" הופך את ההזמנה אוטומטית לתנועת הכנסה.
- **דוחות** — רווח/הפסד חודשי, פילוח לפי ערוץ מכירה, פילוח לפי אמצעי תשלום, פילוח הוצאות לפי קטגוריה, ומה נמכר הכי הרבה (כמות + ₪).
- **רשימת קניות/חומרים** — הוספה, סימון "נקנה", מחיקה.
- **הגדרות** — ייצוא נתונים ל-CSV/Excel (הכל / חודש / שנה).
- **אפליקציה לטלפון (PWA)** — אפשר "להוסיף למסך הבית" ולפתוח כמו אפליקציה רגילה, ועובדת גם ברשת חלשה.

## הוראות התקנה — צעד אחר צעד

> אין צורך לדעת לתכנת. פשוט עקבי אחרי השלבים לפי הסדר. לוקח בערך 15–20 דקות בפעם הראשונה.

### חלק 1 — יצירת פרויקט ב-Firebase

1. היכנסי ל-<https://console.firebase.google.com> והתחברי עם חשבון Google.
2. לחצי על **"Add project"** (הוספת פרויקט).
3. תני שם, למשל `hana-lima`, ולחצי **Continue**.
4. במסך של Google Analytics — אפשר לכבות את המתג (לא חובה לאפליקציה הזו), ולחצי **Create project**.
5. חכי שהפרויקט ייווצר ולחצי **Continue**.

### חלק 2 — הפעלת Authentication (התחברות)

1. בתפריט הצד לחצי על **Build → Authentication**.
2. לחצי **Get started**.
3. בלשונית **Sign-in method** בחרי **Email/Password**.
4. הפעילי את המתג הראשון (**Email/Password**) ולחצי **Save**.

### חלק 3 — יצירת המשתמש שלך

1. עדיין ב-Authentication, עברי ללשונית **Users**.
2. לחצי **Add user**.
3. הזיני את האימייל והסיסמה שאיתם תתחברי לאפליקציה (בחרי סיסמה חזקה — זה מה שמגן על הנתונים שלך).
4. לחצי **Add user**. זהו — נוצר חשבון ההתחברות היחיד שלך.

### חלק 4 — הפעלת Firestore (מסד הנתונים)

1. בתפריט הצד לחצי **Build → Firestore Database**.
2. לחצי **Create database**.
3. בחרי מיקום קרוב (למשל `eur3 (europe-west)`), לחצי **Next**.
4. בחרי **Start in production mode** ולחצי **Enable**.

### חלק 5 — הדבקת חוקי האבטחה

1. ב-Firestore Database עברי ללשונית **Rules**.
2. מחקי את מה שכתוב שם והדביקי במקום את כל התוכן של הקובץ `firestore.rules` (מצורף בפרויקט).
3. לחצי **Publish**.

זה נועל את הנתונים כך שרק החשבון שלך (ה-uid שלך) יכול לקרוא ולכתוב.

### חלק 6 — העתקת ה-config והדבקתו בקוד

1. בתפריט הצד לחצי על גלגל השיניים ⚙️ → **Project settings**.
2. גללי למטה ל-**"Your apps"** ולחצי על אייקון הווב **`</>`**.
3. תני כינוי לאפליקציה (למשל `hana-lima-web`) ולחצי **Register app**. (אין צורך לסמן Hosting.)
4. יוצג לך בלוק קוד עם `const firebaseConfig = { ... }`. העתיקי את הערכים.
5. פתחי את הקובץ `firebase-config.js` והחליפי את השדות עם ה-`YOUR_...` בערכים האמיתיים שלך. לדוגמה:

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "hana-lima.firebaseapp.com",
  projectId: "hana-lima",
  storageBucket: "hana-lima.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123...:web:abc...",
};
```

6. שמרי את הקובץ.

> אין בעיה שה-config הזה "גלוי" בקוד — הוא לא סוד. מה שמגן על הנתונים זה חוקי האבטחה מחלק 5 + הסיסמה שלך.

## חלק 7 — העלאה ל-GitHub Pages (כדי שתהיה כתובת אתר)

1. פתחי חשבון (אם אין) ב-<https://github.com> והתחברי.
2. לחצי על **+** בפינה למעלה → **New repository**.
3. תני שם, למשל `hana-lima`, בחרי **Public**, ולחצי **Create repository**.
4. במסך הריק שנפתח לחצי על הקישור **"uploading an existing file"**.
5. גררי לשם את כל הקבצים מהפרויקט: `index.html`, `styles.css`, `app.js`, `firebase-config.js` (עם הערכים שהדבקת), `firestore.rules`, `README.md`.
6. לחצי **Commit changes**.
7. עברי ל-**Settings** (בתפריט העליון של ה-repository) → **Pages** (בתפריט הצד).
8. תחת **Branch** בחרי `main` ואת התיקייה `/ (root)`, ולחצי **Save**.
9. חכי דקה-שתיים, רענני את העמוד — תופיע כתובת כמו:
   `https://<שם-המשתמש-שלך>.github.io/hana-lima/`
10. פתחי את הכתובת מהטלפון והתחברי עם האימייל והסיסמה מחלק 3. 🎉

> **טיפ:** בטלפון, פתחי את הכתובת בדפדפן ובחרי **"הוסף למסך הבית"** — האפליקציה תיראה ותתנהג כמו אפליקציה רגילה (בזכות ה-PWA).

> **אם ההתחברות לא עובדת מהכתובת החדשה:** ב-Firebase → Authentication → לשונית **Settings** → **Authorized domains** → **Add domain**, והוסיפי את הדומיין `<שם-המשתמש>.github.io`. (localhost כבר מאושר אוטומטית, לכן הבדיקה המקומית עובדת בלי זה.)

**האם הנתונים מסונכרנים בין הטלפון לאייפד ולמחשב?**
כן. הכול נשמר ב-Firestore ומתעדכן בזמן אמת בכל מכשיר שמחובר עם אותו חשבון.

אפשר להוסיף רישומים גם בלי חיבור — הם יישמרו במכשיר ויסתנכרנו כשהרשת תחזור.

**כמה זה עולה?**
לשימוש אישי בהיקף כזה — התוכנית החינמית של Firebase יותר מספיקה.

**איך מגבים / מוציאים דוח?**
בהגדרות → "ייצוא ל-CSV / Excel". נוצר קובץ שנפתח ישירות ב-Excel (כולל עברית תקינה).
